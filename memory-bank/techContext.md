# Technology Context: Cells Contraction Monitor

## Core Technology Stack
- **Language**: Python 3.10+ for scientific computing ecosystem
- **Neural Networks**: ONNX Runtime for cross-platform inference
- **Computer Vision**: OpenCV 4.8+ for image processing
- **Scientific Libraries**: NumPy, SciPy
- **UI**: Tkinter for cross-platform GUI, Matplotlib for visualization
- **Data**: JSON-based annotations, CSV export, multiple format support

## Development Tools
- **Package Management**: Poetry for dependencies and distribution
- **Testing**: pytest for unit and integration tests
- **Quality**: Black for formatting, MyPy for type checking
- **Version Control**: Git with GitHub Flow and conventional commits

## Performance & Scalability
- **Memory Management**: Streaming processing for large datasets
- **Parallel Processing**: Multi-threading and async I/O
- **Hardware Acceleration**: GPU support via CUDA/OpenCL
- **Optimization**: Vectorization and SIMD instructions
